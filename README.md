# DevOps

A WISER plugin for people who run their own servers and self-hosted applications: virtual machines, Docker workloads, light security, and setting up each organisation's use of applications such as Twenty CRM. It ships two experts, DevOps Expert and CRM Expert, eight skills, Prepare VM, VM Inventory, VM Configure, VM Security Audit, Deploy Workload, Deploy Twenty, Back Up Twenty and Set Up Twenty Workspace, and one tool, vm-job.

## Install

Point your harness at this repository as a plugin root, or add the repository as a marketplace and install `devops@wiser-method-devops` from its catalog.

Work lands in the working folder you attach, never in this repository.
